# 🚀 PokerNow GTO HUD - 빠른 설치 가이드

## 📦 다운로드

아래 위치에서 파일을 가져올 수 있습니다:

### 옵션 1: ZIP 파일 (권장)
```
/app/pokernow-gto-hud.zip
```
- 모든 파일이 포함된 압축 파일
- 다운로드 후 압축 해제

### 옵션 2: 개별 파일
```
/app/chrome-extension/
```
- 폴더 전체를 복사

## 🔧 Chrome 설치 (3단계)

### 1단계: 압축 해제
```bash
# Windows
# 파일 우클릭 → "압축 풀기"

# Mac/Linux
unzip pokernow-gto-hud.zip
```

### 2단계: Chrome 익스텐션 페이지 열기
1. Chrome 브라우저 실행
2. 주소창에 입력: `chrome://extensions/`
3. Enter

### 3단계: 익스텐션 로드
1. 우측 상단 **"개발자 모드"** 토글 ON
2. 좌측 상단 **"압축해제된 확장 프로그램을 로드합니다"** 클릭
3. 압축 해제한 `chrome-extension` 폴더 선택
4. **"선택"** 클릭

## 🎮 첫 사용

### 1. PokerNow 접속
- https://www.pokernow.club
- 또는 https://www.pokernow.com

### 2. 게임 시작
- 기존 게임 참가 또는
- 새 게임 생성

### 3. HUD 확인
- 화면 우측 하단에 **GTO HUD** 자동 표시
- 초록색 상태 표시등 깜빡임

### 4. HUD 사용
- **드래그**: 상단 헤더를 드래그하여 이동
- **정보 확인**: 실시간으로 자동 업데이트 (1초마다)

## 🔧 문제 해결

### HUD가 안 보여요
1. F12 눌러서 개발자 콘솔 확인
2. 익스텐션이 활성화되어 있는지 확인
3. 페이지 새로고침 (Ctrl+R / Cmd+R)

### 카드 정보가 안 떠요
1. 게임 테이블에 제대로 입장했는지 확인
2. 핸드가 시작되었는지 확인
3. 1-2초 기다리기 (자동 업데이트 주기)

### 포지션이 이상해요
1. 9-Max 테이블인지 확인 (6-Max도 지원)
2. 딜러 버튼이 화면에 보이는지 확인
3. 익스텐션 재로드 후 재시도

### 익스텐션 재로드 방법
1. `chrome://extensions/` 접속
2. PokerNow GTO HUD 찾기
3. 새로고침 아이콘 클릭
4. 게임 페이지 새로고침

## ⚠️ 중요 공지

이 도구는 포커 GTO 전략을 학습하고 이해하기 위한 교육용 도구입니다.

### 이용 약관
실제 금전이 걸린 게임에서 사용하기 전에:

- 보조 도구 사용 허용 여부 확인
- 공정한 게임 문화 존중

### 정확도
- DOM 스크래핑 기반으로 100% 정확도 보장 불가
- 사이트 업데이트 시 일부 기능 작동 안 할 수 있음
- 참고용으로만 사용 권장
