# PokerNow GTO HUD Chrome Extension

pokernow.club/com용 실시간 9-Max GTO 프리플랍 가이드 및 포스트플랍 승률 기반 액션 추천 HUD

## 🎯 주요 기능

### ✅ 실시간 정보 표시
- **내 카드**: 현재 내가 가진 2장의 홀 카드
- **포지션**: 9-Max 포지션 자동 감지 (UTG ~ BB)
- **보드 카드**: 플랍/턴/리버 커뮤니티 카드
- **GTO 액션 추천**: Check/Raise/Fold 각 퍼센트
- **팟 오즈**: 현재 상황의 팟 오즈 계산
- **승률 (Equity)**: 몬테카를로 시뮬레이션 기반 정확한 승률

### 🎲 정확한 계산 엔진
- **몬테카를로 시뮬레이션**: 5,000회 시뮬레이션으로 정확한 승률 계산
- **7카드 핸드 평가**: 최고의 5카드 조합 자동 선택
- **실시간 팟 오즈 계산**: 동적 베팅 상황 반영

### 📊 포괄적인 GTO 데이터
- **RFI 레인지**: 9-Max 100BB 포지션별 오픈 레인지
- **3bet 레인지**: 포지션 vs 포지션 3bet 레인지
- **4bet 레인지**: 포지션별 4bet 레인지

### 🎨 사용자 친화적 UI
- **드래그 가능**: 화면 어디든 자유롭게 이동
- **다크모드**: 눈이 편한 반투명 다크 테마
- **실시간 업데이트**: 1초마다 자동 갱신
- **방해 없음**: 게임 버튼 클릭에 영향 없음

## 📦 설치 방법

### 1. 파일 다운로드
모든 익스텐션 파일을 로컬 폴더에 다운로드합니다:
```
chrome-extension/
├── manifest.json
├── content.js
├── styles.css
├── hand-evaluator.js
├── equity-calculator.js
├── gto-ranges.js
└── position-detector.js
```

### 2. Chrome에 로드
1. Chrome 브라우저에서 `chrome://extensions/` 접속
2. 우측 상단 "개발자 모드" 활성화
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. `chrome-extension` 폴더 선택

### 3. 확인
- 익스텐션 목록에 "PokerNow GTO HUD" 표시 확인
- 활성화 상태 확인

## 🎮 사용 방법

### 자동 활성화
1. pokernow.club 또는 pokernow.com 접속
2. 게임 테이블에 입장
3. HUD가 자동으로 우측 하단에 표시됨

### HUD 이동
- HUD 상단 헤더를 드래그하여 원하는 위치로 이동

### 정보 읽기
- **초록색 배지**: 현재 포지션
- **액션 추천**: 가장 높은 퍼센트가 하이라이트됨
- **승률 vs 팟 오즈**: 초록색(유리)/빨간색(불리)

## 🧮 계산 로직

### 프리플랍
1. 내 카드를 표준 포맷으로 변환 (예: AKs, 77)
2. 현재 포지션의 GTO 레인지 확인
3. 레인지 내: Raise 100%
4. 레인지 외: Fold 100%

### 포스트플랍
1. 5,000회 몬테카를로 시뮬레이션으로 승률 계산
2. 팟 오즈 계산: 콜 금액 / (팟 + 콜 금액)
3. 승률 > 팟 오즈: Positive EV
   - 큰 우위 (20%+): Raise 70% / Call 30%
   - 중간 우위 (10-20%): Raise 50% / Call 50%
   - 작은 우위 (5-10%): Raise 30% / Call 70%
   - 근소한 우위 (<5%): Raise 10% / Call 90%
4. 승률 < 팟 오즈: Negative EV
   - Fold 100%

### MDF (Minimum Defense Frequency)
상대의 베팅에 대해 너무 자주 폴드하지 않도록 MDF 고려:
- 승률이 팟 오즈의 70% 이상: Call 60% / Fold 40%

## 🎯 GTO 레인지 개요

### RFI (Raise First In) - 선별된 포지션
**UTG (가장 타이트)**
- 프리미엄: AA-99, AKs-ATs, AKo-AQo
- 수트 커넥터: A5s-A2s, KQs-K9s, QJs-QTs, JTs-J9s
- 범위: ~12%

**HJ (미들)**
- 모든 페어: AA-22
- Ax suited: AKs-A2s
- 브로드웨이: AKo-A8o, KQo-KTo
- 수트 커넥터 확장: T6s, 86s, 43s
- 범위: ~22%

**BTN (가장 와이드)**
- 거의 모든 페어와 수트 핸드
- Ax offsuit: AKo-A2o
- Kx, Qx, Jx 확장
- 범위: ~45%
